# Suthasinee O. - Data Analyst Portfolio

A clean, minimalist personal portfolio website built with HTML and CSS, featuring a dark/light mode toggle.

## Features
- **Responsive Design**: Works on mobile, tablet, and desktop.
- **Dark/Light Mode**: User-selectable theme with persistence using local storage.
- **Project Showcase**: A grid-based layout to display data analysis projects.
- **Minimalist Aesthetic**: Uses the 'JetBrains Mono' font for a clean, technical look.

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS with CSS Variables)
- JavaScript (for theme switching)
